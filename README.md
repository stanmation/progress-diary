# Progress Diary

A React Native progress tracking application built with TypeScript.

## Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn
- Expo CLI

### Installation

```bash
npm install
```

### Running the App

#### On Expo (Web)
```bash
npm start
```

Then press `w` in the terminal to open in web browser, or `i` for iOS, `a` for Android.

#### On iOS
```bash
npm run ios
```

#### On Android
```bash
npm run android
```
